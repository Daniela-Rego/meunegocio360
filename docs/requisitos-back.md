# Projeto Meu Negócio 360 - Documento de Requisitos (Back-end)

- Runtime: Node.js
- Linguagem: TypeScript
- Framework: NestJS
- Banco de dados: PostgreSQL
- Arquitetura: API REST baseada em microserviços
- Padrão arquitetural: cada microserviço será organizado em camadas, seguindo o padrão MVC adaptado para APIs
- Comunicação entre microserviços: a definir, podendo utilizar HTTP/REST ou mensageria
